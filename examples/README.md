# StochX examples

The examples are executable documentation for the time-series package. They cover the practical workflow from data/workfiles through estimation, diagnostics, state-space analysis and forecasting.

Run from the repository root after installing StochX:

```bash
python examples/07_api_operations.py
python examples/08_eviews_time_series_workflow.py
python examples/09_state_space_kalman.py
python examples/10_state_space_workflow.py
python examples/api_quickstart.py
```

The examples intentionally use the current `stochx.timeseries` public API. The documentation examples are kept runnable so they serve as executable references for the package surface.
