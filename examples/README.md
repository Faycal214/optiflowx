# StochX examples

The examples are executable documentation. Each course area has a focused example, and `07_api_operations.py` is the public-API coverage gallery.

Run from the repository root after installing StochX:

```bash
python examples/01_discrete_markov_chain.py
python examples/02_poisson_process.py
python examples/02_poisson_complete.py
python examples/03_continuous_markov_chain.py
python examples/03_cmtc_complete.py
python examples/04_birth_death_process.py
python examples/05_conditional_expectation.py
python examples/05_conditional_expectation_complete.py
python examples/06_martingale.py
python examples/api_quickstart.py
python examples/07_api_operations.py
```

The complete examples demonstrate the major mathematical operations for their domain. The API gallery additionally exercises the public classes and meaningful public operations so the runnable examples serve as an executable reference for the library surface.

The examples intentionally use the same terminology as the Package / API pages while keeping mathematical exposition in the Course Material section.
