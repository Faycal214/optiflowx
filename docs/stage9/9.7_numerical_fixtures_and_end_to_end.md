# Stage 9.7 — Numerical Fixtures and End-to-End Regression

Stage 9.7 freezes one deterministic Box–Jenkins path from candidate estimation through residual validation, model selection, and forecasting.

## Fixture design

The fixture is intentionally independent of StochX's simulator. It reproduces the ARMA(1,1) recursion directly with:

- `nobs = 180`
- `phi = 0.45`
- `theta = 0.25`
- Gaussian innovations
- `rng = 42`
- `burnin = 500`
- validation lags `8`
- selection criterion `AIC`
- forecast horizon `5`
- `alpha = 0.05`

Frozen numerical targets include the selected `(1,0,1)` coefficients, standard errors, t-statistics, p-values, log likelihood, SIGMASQ, AIC, SC, HQ, AR/MA roots, and five-step forecast/interval arrays.

## End-to-end acceptance criteria

The regression suite requires:

1. all deterministic candidate orders to estimate or produce an auditable structured failure;
2. serially inadequate candidates to be excluded from selection;
3. at least one adequate candidate;
4. deterministic AIC selection of `(1,0,1)` for the frozen fixture;
5. coefficient and model-statistic numerical parity within the fixture tolerance;
6. deterministic point forecasts and prediction intervals;
7. interval ordering `Lower <= Forecast <= Upper`;
8. correct future DatetimeIndex continuation;
9. explicit inverse-differencing restoration and restoration metadata;
10. frozen Stage 8 correlogram fields, table schema, lag/DF behavior, and immutable AC/PAC arrays remain unchanged.

## Numerical policy

The fixture uses field-level absolute/relative tolerances rather than string comparison. Changes to estimator mathematics, likelihood conventions, information criteria, root computation, or forecast construction that move the frozen values outside those tolerances must be reviewed as numerical-contract changes.

Stage 9.7 does not modify any Stage 8 implementation. Its correlogram assertions are compatibility checks only.
