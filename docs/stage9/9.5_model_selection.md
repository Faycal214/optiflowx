# Stage 9.5 — Deterministic Model Selection

Stage 9.5 selects the final Box–Jenkins candidate only from the candidates that passed Stage 9.4 residual adequacy filtering.

## Eligibility gate

Candidates that failed estimation or residual validation are never considered. If the eligible set is empty, selection returns the explicit `no_adequate_model` status and does not force a model choice.

## Criterion

The caller must use one explicit information criterion:

- `aic`: Akaike information criterion;
- `sc` or `bic`: Schwarz/Bayesian information criterion;
- `hq`: Hannan–Quinn criterion.

For all three criteria, smaller values are preferred.

`bic` is an alias of `sc`; the result records the normalized criterion name `sc`.

## Tie breaking

A criterion difference `<= tie_tolerance` is treated as a tie. Ties are resolved deterministically:

1. prefer the candidate with fewer estimated parameters;
2. if still tied, prefer lexicographically smaller `(p,d,q)`.

No candidate is re-estimated or revalidated during selection.

## Public API

```python
from stochx.timeseries import select_box_jenkins_model

selection = select_box_jenkins_model(
    validation,
    criterion="aic",
    tie_tolerance=1e-8,
)
```

The result exposes:

- `selected` — the chosen `EstimatedCandidate`, or `None`;
- `selected_order`;
- `status` — `selected` or `no_adequate_model`;
- `eligible_orders`;
- `ranked_candidates`;
- `rationale`;
- `table()` — the deterministic ranking table.

## Audit rule

The rationale must identify the criterion, winning value, number of eligible candidates, and whether a tolerance tie required parsimony/order tie-breaking.

## Stage 8 preservation

Selection does not modify or reinterpret the Stage 8 correlogram, Ljung–Box, DF, confidence-band, missing-value, result-object, alias, table, or immutability contracts. It consumes only the Stage 9.4 eligibility output.

## Acceptance criteria

Stage 9.5 is complete when:

- only Stage 9.4 eligible candidates can be selected;
- AIC, SC/BIC, and HQ selection are individually testable;
- lower criterion values are preferred;
- tolerance ties resolve by parameter-count parsimony and then `(p,d,q)` order;
- no-adequate-model remains explicit;
- ranking and rationale are deterministic;
- the selection result is auditable;
- no re-estimation or residual revalidation occurs during selection;
- Stage 8 remains unchanged.
