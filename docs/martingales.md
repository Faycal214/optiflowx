# Discrete-Time Martingales

This page gives a compact mathematical reference for filtrations, adapted processes, martingales, stopping times, and stopped processes.

## 1. Filtration

A filtration is an increasing sequence of sigma-fields

$$
\mathcal F_0\subseteq\mathcal F_1\subseteq\cdots.
$$

In StochX, each finite \(\mathcal F_n\) is represented by a `Partition`:

```python
filtration = Filtration([F0, F1, F2])
```

The inclusion of sigma-fields is represented through refinement of partitions.

## 2. Adapted process

A process \((X_n)\) is adapted to \((\mathcal F_n)\) if

$$
X_n\text{ is }\mathcal F_n\text{-measurable}
$$

for every \(n\).

```python
filtration.is_adapted(process)
```

The natural filtration is generated by the information observed through the process up to time \(n\):

```python
Filtration.natural(process)
```

## 3. Martingale

An integrable, adapted process is a martingale when

$$
E[X_{n+1}\mid\mathcal F_n]=X_n.
$$

Equivalently,

$$
E[(X_{n+1}-X_n)\mid\mathcal F_n]=0.
$$

StochX can evaluate the residual directly:

```python
mart.martingale_residual(n)
mart.is_martingale()
```

## 4. Submartingale and supermartingale

A supermartingale satisfies

$$
E[X_{n+1}\mid\mathcal F_n]\le X_n,
$$

while a submartingale satisfies

$$
E[X_{n+1}\mid\mathcal F_n]\ge X_n,
$$

with the required integrability and adaptedness conditions.

```python
mart.is_submartingale()
mart.is_supermartingale()
```

## 5. Multi-step conditional expectation

For a martingale,

$$
E[X_{n+k}\mid\mathcal F_n]=X_n,
\qquad k\ge0.
$$

```python
mart.conditional_future(n, k)
```

## 6. Doob martingale

If \((\mathcal F_n)\) is a filtration and \(X\) is integrable, then

$$
X_n=E(X\mid\mathcal F_n)
$$

defines a martingale, called the Doob martingale.

```python
mart = Martingale.doob(terminal_variable, filtration)
```

## 7. Convex transformations

For a convex function \(\varphi\), Jensen's inequality gives

$$
\varphi(E(X))\le E(\varphi(X)).
$$

Under the required integrability conditions, a convex transformation of a martingale is a submartingale, while a concave transformation gives a supermartingale.

The general transformation is represented by the `Martingale` API where supported.

## 8. Random-walk example

Consider the symmetric random walk

$$
X_n=\sum_{i=1}^{n}\xi_i,
$$

where the independent increments \(\xi_i\) take values \(-1\) and \(1\) with probability \(1/2\). The corresponding process and filtration can be represented in the finite framework and tested with `Martingale.is_martingale()`.

## 9. Stopping times

A stopping time \(T\) takes values in \(\mathbb N\cup\{+\infty\}\) and satisfies

$$
\{T=n\}\in\mathcal F_n,
$$

with equivalent formulations using \(\{T\le n\}\) or \(\{T>n\}\).

```python
T = StoppingTime.from_values(
    space,
    values,
    filtration,
)
```

The construction checks compatibility with the available filtration information.

Useful operations include

```python
T.minimum(S)   # T ∧ S
T.maximum(S)   # T ∨ S
T.add(S)       # T + S
```

## 10. Stopped process

For an adapted process \((X_n)\) and a stopping time \(T\),

$$
X_n^T=X_{n\wedge T}.
$$

Equivalently,

$$
X_n^T
=
X_n\mathbf1_{\{n<T\}}
+X_T\mathbf1_{\{T\leq n\}}.
$$

```python
stopped = mart.stopped(T)
stopped.values(n)
stopped.sequence()
```

When the original process is a martingale, the stopped process is again a martingale under the corresponding assumptions.

## 11. Terminal variable

When \(T\) is almost surely finite, the terminal variable \(X_T\) is defined and the stopped process converges to it in the represented finite setting.

```python
terminal = stopped.terminal_value()
```

If an outcome has \(T=+\infty\), `terminal_value()` refuses to construct an undefined terminal value.
