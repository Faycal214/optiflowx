# Stage 10.3 — Deterministic Numerical Fixtures

Stage 10.3 freezes the numerical-reference layer for the Stage 10.2 state-space and Kalman-filter core. It adds independent deterministic fixtures without changing the Stage 10.2 public API or numerical conventions.

## Fixture inventory

The fixture directory is `tests/fixtures/stage10_statespace/`.

- `scalar_local_level.json`: hand-calculated scalar Kalman recursion.
- `scalar_dynamic.json`: independent scalar state-space recursion with non-trivial transition, process variance, observation variance, and five observations.
- `multivariate_missing.json`: independent two-state/two-observation recursion covering partial and fully missing rows.

The fixture README records the source hierarchy, reproducibility rules, scalar observation accounting, and tolerances.

## Reference hierarchy

Expected values should come from the strongest independent source available:

1. analytical or hand calculation;
2. independent reference recursion;
3. trusted external implementation with documented parameterization.

Expected values must not be generated solely by calling the StochX implementation under test at test time.

## Reproducibility

Every fixture records its complete model specification, initial conditions, observations, expected outputs, and tolerance policy. The fixtures contain no ambient randomness, time dependence, or environment-dependent ordering.

Random data may be added in later stages only with an explicit generator and frozen seed.

## Numerical tolerance policy

Structural counts, shapes, and observation masks use exact equality.

Default floating-point fixture tolerance:

```text
rtol = 1e-10
atol = 1e-12
log-likelihood atol = 1e-10
```

The hand-calculated local-level fixture uses `1e-12` absolute tolerance for its scalar values and likelihood.

Tolerances may only be relaxed with fixture-level justification. A tolerance increase must not be used as a substitute for diagnosing a numerical discrepancy.

## Missing-observation convention

The Stage 10.2 convention remains frozen:

- `nobs` counts time rows;
- `effective_nobs` counts observed scalar measurements;
- `missing_observations` counts missing scalar measurements;
- partial rows update only observed dimensions;
- fully missing rows perform prediction only and contribute no likelihood increment.

For a two-dimensional four-row example with five observed scalars, the fixture therefore records `nobs=4`, `effective_nobs=5`, and `missing_observations=3`.

## Test layout

`tests/test_stage10_statespace_fixtures.py` verifies:

- analytical scalar parity;
- independent scalar parity;
- multivariate missing-observation parity;
- exact observation accounting;
- input immutability;
- covariance symmetry;
- repeatability.

The tests use the public Stage 10.2 APIs only. Fixture-specific helpers are limited to loading fixture data and constructing public model objects.

## Compatibility

Stage 10.3 does not change:

- `LinearStateSpace`;
- `KalmanFilterResult`;
- `kalman_filter()`;
- `local_level_filter()`;
- Stage 8 correlogram and numerical contracts;
- Stage 9 Box–Jenkins APIs and numerical behavior.
