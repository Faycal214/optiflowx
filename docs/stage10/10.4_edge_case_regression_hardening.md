# Stage 10.4 — Edge-Case and Regression Hardening

## Purpose

Stage 10.4 hardens the Stage 10.2 state-space/Kalman core against degenerate, boundary, malformed, missing, and numerically singular inputs without changing its public numerical contract.

## Frozen compatibility boundary

Stage 10.4 preserves the Stage 10.2 public APIs:

- `LinearStateSpace`
- `KalmanFilterResult`
- `kalman_filter()`
- `local_level_filter()`

It also preserves the Stage 8 and Stage 9 contracts.

## Hardening coverage

The regression suite covers:

- all-missing scalar samples;
- fully missing rows as prediction-only steps;
- singular zero-process/zero-observation-noise models;
- deterministic singular-model repeatability;
- state and observation intercepts;
- single-observation samples;
- wrong observation dimensions;
- non-finite model matrices;
- empty local-level samples;
- empty controls with zero control columns;
- explicit rejection of unsupported non-empty controls.

## Numerical stability rule

Innovation covariance matrices are symmetrized and, when numerically singular, receive a minimal deterministic positive jitter before linear solves and likelihood evaluation. Ordinary well-conditioned results are unchanged.

A singular model must not produce NaNs, infinities, or platform-dependent behavior merely because the innovation covariance is positive semidefinite rather than strictly positive definite.

## Missing-observation rule

Missingness remains scalar-observation based:

- `nobs` counts time rows;
- `effective_nobs` counts finite scalar measurements;
- `missing_observations` counts missing scalar measurements;
- an all-missing row performs prediction only;
- an all-missing row contributes zero log-likelihood.
