# API coverage status

The package exposes mathematical objects for CMTD, Poisson processes, CMTC, birth-death processes, conditional expectation, filtrations, martingales, stopping times, and stopped processes.

Use `docs/api.md` for the current component inventory and `examples/README.md` for executable examples.

The API-quality pass is focused on class-level docstrings, explicit contracts, canonical syntax, and examples that exercise the public surface rather than isolated demonstrations.
