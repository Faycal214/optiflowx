# Birth-Death Processes

A birth-death process is a continuous-time Markov process whose state changes only by one unit at a time.

## 1. Definition

The state space is \(\mathbb N\). From state \(k\), the only possible jumps are

\[
k\longrightarrow k+1
\qquad\text{and}\qquad
k\longrightarrow k-1.
\]

Let \(\lambda_k\) be the birth rate and \(\mu_k\) the death rate. The generator has the form

\[
q_{k,k+1}=\lambda_k,
\qquad
q_{k,k-1}=\mu_k,
\qquad
q_{k,k}=-(\lambda_k+\mu_k),
\]

with the appropriate boundary adjustments.

```python
from optiflowx.stochastic import BirthDeathProcess

process = BirthDeathProcess(
    birth_rates=lambda k: 0.4 * k,
    death_rates=lambda k: 0.2 * k,
)
```

## 2. Embedded jump chain

When \(\lambda_k+\mu_k>0\), the jump-chain probabilities are

\[
\widetilde p_{k,k+1}
=\frac{\lambda_k}{\lambda_k+\mu_k},
\qquad
\widetilde p_{k,k-1}
=\frac{\mu_k}{\lambda_k+\mu_k}.
\]

For a finite model:

```python
process.jump_chain_matrix()
process.to_ctmc()
```

## 3. Kolmogorov equations

Let

\[
p_k(t)=P(X_t=k).
\]

The state probabilities satisfy the birth-death balance equations generated by \(Q\). For a finite model, `kolmogorov_derivative` represents \(p'(t)=p(t)Q\) using the row-vector convention of the package.

```python
p_derivative = process.kolmogorov_derivative(probabilities)
```

## 4. Stationary distribution

Define

\[
\rho_0=1,
\qquad
\rho_k=\rho_{k-1}\frac{\lambda_{k-1}}{\mu_k}.
\]

When normalization is possible, these weights determine the stationary distribution.

```python
weights = process.stationary_weights(n_terms=20)
```

For a finite model, the stationary distribution can also be obtained through the associated CTMC:

```python
pi = process.stationary_distribution()
```

## 5. Pure immigration

For

\[
\lambda_k=\alpha>0,
\qquad
\mu_k=0,
\]

the process reduces to a Poisson counting model and

\[
P(X_t=n)=e^{-\alpha t}\frac{(\alpha t)^n}{n!}.
\]

```python
BirthDeathProcess.pure_immigration_probability(
    n=3,
    t=2.0,
    rate=alpha,
)
```

## 6. Pure birth

For

\[
\lambda_n=n\lambda,
\qquad
\mu_n=0,
\]

the corresponding probability is available through

```python
BirthDeathProcess.pure_birth_probability(
    n=4,
    t=2.0,
    rate=lam,
)
```

The same model is connected to non-explosion through the reciprocal-rate series. The package exposes a finite partial sum:

```python
process.pure_birth_reciprocal_rate_sum(n_terms=100)
```

A finite truncation is not treated as a proof of convergence of the infinite series.

## 7. Pure death

For

\[
\lambda_n=0,
\qquad
\mu_n=n\mu,
\]

the remaining population has a binomial-type law when starting from a fixed initial population.

```python
BirthDeathProcess.pure_death_probability(
    n=3,
    t=2.0,
    initial_population=10,
    rate=mu,
)
```

## 8. Linear rates

A common family is

\[
\lambda_n=n\lambda+\alpha,
\qquad
\mu_n=n\mu+\beta,
\]

where \(\alpha\) represents immigration and \(\beta\) represents emigration.

```python
process = BirthDeathProcess.linear(
    birth_rate=lam,
    death_rate=mu,
    immigration=alpha,
    emigration=beta,
)
```
