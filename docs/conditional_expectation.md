# Conditional Expectation

This page gives a compact mathematical reference for conditional expectation in finite probability spaces and shows how the concepts map to OptiFlowX.

## 1. Conditioning on an event

For an event \(B\) such that \(P(B)>0\),

\[
P(A\mid B)=\frac{P(A\cap B)}{P(B)}
\]

and for an integrable random variable \(X\),

\[
E(X\mid B)=\frac{E(X\mathbf1_B)}{P(B)}.
\]

In OptiFlowX:

```python
space.conditional_probability_given_event(A, B)
space.conditional_expectation_given_event(X, B)
```

## 2. Finite probability space and random variable

The finite framework represents outcomes and their probabilities explicitly:

```python
space = FiniteProbabilitySpace(
    outcomes=[...],
    probabilities=[...],
)
X = space.random_variable([...], name="X")
```

Expectation is the weighted sum

\[
E(X)=\sum_{\omega\in\Omega}X(\omega)P(\{\omega\}).
\]

```python
X.expectation()
```

## 3. Conditioning with respect to a sigma-field

For a sub-sigma-field \(\mathcal G\), conditional expectation \(E(X\mid\mathcal G)\) is a \(\mathcal G\)-measurable random variable satisfying

\[
\int_AE(X\mid\mathcal G)\,dP
=
\int_AX\,dP,
\qquad A\in\mathcal G.
\]

In the finite representation, a sigma-field is represented by a `Partition`. On a block \(G\) with positive probability,

\[
E(X\mid\mathcal G)(\omega)
=
\frac{\sum_{u\in G}X(u)P(\{u\})}{P(G)},
\qquad \omega\in G.
\]

```python
G = space.partition([
    {"omega_1", "omega_2"},
    {"omega_3", "omega_4"},
])
conditioned = space.conditional_expectation(X, G)
```

## 4. Conditioning with respect to a random variable

When the sigma-field is generated by a random variable \(Y\),

\[
E(X\mid\sigma(Y))=E(X\mid Y).
\]

Similarly,

\[
P(A\mid\mathcal G)=E(\mathbf1_A\mid\mathcal G).
\]

The partition generated by \(Y\) groups outcomes with equal values:

```python
G_Y = Partition.generated_by(Y)
E_X_given_Y = space.conditional_expectation_given(X, Y)
```

## 5. Fundamental properties

### Measurability

If \(X\) is \(\mathcal G\)-measurable,

\[
E(X\mid\mathcal G)=X\quad\text{a.s.}
\]

### Linearity

\[
E(aX+bY\mid\mathcal G)
=aE(X\mid\mathcal G)+bE(Y\mid\mathcal G).
\]

### Positivity

If \(X\ge0\), then

\[
E(X\mid\mathcal G)\ge0.
\]

### Total expectation

\[
E(E(X\mid\mathcal G))=E(X).
\]

```python
space.total_expectation(X, G)
```

## 6. Tower property

If \(\mathcal G_1\subseteq\mathcal G_2\), then

\[
E(E(X\mid\mathcal G_2)\mid\mathcal G_1)
=
E(X\mid\mathcal G_1).
\]

In the partition representation:

```python
space.tower(X, finer, coarser)
```

## 7. Pull-out property

If \(Y\) is \(\mathcal G\)-measurable,

\[
E(YX\mid\mathcal G)=Y E(X\mid\mathcal G).
\]

```python
residual = space.pull_out(Y, X, G)
```

## 8. Conditional probability as conditional expectation

The relation

\[
P(A\mid\mathcal G)=E(\mathbf1_A\mid\mathcal G)
\]

connects conditional probability with conditional expectation.

```python
space.conditional_probability(A, G)
```

## 9. Conditional variance and covariance

For square-integrable variables,

\[
Var(X\mid\mathcal G)
=E(X^2\mid\mathcal G)-E(X\mid\mathcal G)^2,
\]

and

\[
Cov(X,Y\mid\mathcal G)
=E(XY\mid\mathcal G)
-E(X\mid\mathcal G)E(Y\mid\mathcal G).
\]

```python
space.conditional_variance(X, G)
space.conditional_covariance(X, Y, G)
```

## 10. Total variance and covariance

The corresponding decompositions are

\[
Var(X)
=E[Var(X\mid\mathcal G)]
+Var(E[X\mid\mathcal G]),
\]

and

\[
Cov(X,Y)=E[Cov(X,Y\mid\mathcal G)]
+Cov(E[X\mid\mathcal G],E[Y\mid\mathcal G]).
\]

```python
space.total_variance(X, G)
space.total_covariance(X, Y, G)
```

## 11. Projection in \(L^2\)

For square-integrable variables, conditional expectation can be interpreted as projection onto the subspace of \(\mathcal G\)-measurable variables.

```python
space.l2_projection(X, G)
```
