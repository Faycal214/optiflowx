# Worked examples

The repository contains one runnable example for each course area.

| Example | Course object |
|---|---|
| `examples/01_discrete_markov_chain.py` | CMTD / `MarkovChain` |
| `examples/02_poisson_process.py` | Poisson process |
| `examples/03_continuous_markov_chain.py` | CMTC |
| `examples/04_birth_death_process.py` | Birth-death process |
| `examples/05_conditional_expectation.py` | Conditional expectation |
| `examples/06_martingale.py` | Discrete-time martingale |

Each example should remain small enough to read in one pass and should correspond to a mathematical concept explained in the Course material section.

The CI workflow executes these scripts and builds the documentation so that examples do not drift away from the public API.
