# Stage 11.1 — State-Space Extension

Stage 11 extends the frozen Stage 10 linear-Gaussian state-space API with deterministic Rauch–Tung–Striebel (RTS) smoothing.

## Public API

```python
from stochx.timeseries import KalmanSmootherResult, kalman_smoother
```

`kalman_smoother(observations, model, filter_result=None)` accepts the same observation/model contract as `kalman_filter()`. When a compatible `filter_result` is supplied it is reused; otherwise the forward filter is run once internally.

`KalmanSmootherResult` exposes `smoothed_state`, `smoothed_cov`, `filter_result`, and `nobs`, with `states` and `covariances` aliases. Numerical result arrays are immutable.

## RTS recursion

For `t = N-2, ..., 0`:

```text
J_t = P_t F' (P_{t+1|t})^{-1}
x_{t|T} = x_t + J_t (x_{t+1|T} - x_{t+1|t})
P_{t|T} = P_t + J_t (P_{t+1|T} - P_{t+1|t}) J_t'
```

The implementation uses linear solves rather than explicit matrix inversion and symmetrizes each smoothed covariance.

## Invariants

- final smoothed state/covariance equal the final filtered state/covariance;
- one-observation samples return the filter result unchanged;
- state and covariance dimensions are preserved for every time row;
- partial and fully missing observations inherit Stage 10 semantics;
- fully missing rows remain prediction-only in the forward pass and remain present in the smoothed output;
- observations, model, and supplied filter results are not mutated;
- smoothed arrays are read-only;
- repeated execution is deterministic.

## Compatibility

Stage 10 public APIs remain unchanged:

```python
LinearStateSpace
KalmanFilterResult
kalman_filter
local_level_filter
```

Stage 8 correlogram behavior and Stage 9 Box–Jenkins workflows are not redefined by the smoother. The Stage 11 extension consumes their frozen public behavior rather than changing it.
