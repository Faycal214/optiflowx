# Stage 11.2 — State-Space Forecasting and Prediction Intervals

Stage 11.2 extends the frozen Stage 10 linear-Gaussian state-space API with deterministic multi-step forecasting and marginal Gaussian prediction intervals.

## Public API

```python
from stochx.timeseries import KalmanForecastResult, kalman_forecast
```

```python
result = kalman_forecast(
    observations,
    model,
    steps=5,
    alpha=0.05,
)
```

An existing `KalmanFilterResult` may be supplied with `filter_result=` to reuse the Stage 10 filtering pass.

## Numerical convention

The forecast begins at the final filtered state and covariance. For each horizon:

```text
x_(t+h|t) = F x_(t+h-1|t) + c
P_(t+h|t) = F P_(t+h-1|t) F' + Q
```

The observation-space predictive distribution is:

```text
y_(t+h|t) = H x_(t+h|t) + d
S_(t+h|t) = H P_(t+h|t) H' + R
```

The reported `forecast_cov` is the observation-space covariance. Marginal standard errors are the square roots of its diagonal. Prediction limits use the two-sided standard-normal quantile corresponding to `alpha`.

## Missing observations

Historical missing observations retain the Stage 10 semantics. Partial missing rows update only observed dimensions; fully missing rows are prediction-only and do not contribute to the filtering likelihood.

## Index handling

For a pandas `Series` or `DataFrame`, regular `DatetimeIndex` and `RangeIndex` values are extended into the forecast horizon. Plain NumPy inputs receive a deterministic `RangeIndex`.

## Invariants

`KalmanForecastResult` preserves the filtering result used to produce the forecast. Forecast arrays and covariance arrays are immutable. Forecast covariance is symmetrized and its diagonal is clamped at zero only for standard-error extraction to avoid negative roundoff artifacts.

## Failure semantics

`steps` must be a positive integer and `alpha` must lie strictly between 0 and 1. Non-finite non-NaN observations and incompatible supplied filter results are rejected explicitly.

## Compatibility

Stage 11.2 does not modify `LinearStateSpace`, `KalmanFilterResult`, `kalman_filter`, or `local_level_filter`. Stage 8 correlogram contracts and Stage 9 Box–Jenkins contracts remain unchanged.

## Acceptance criteria

- deterministic repeated forecasts;
- correct multi-step state/observation covariance propagation;
- prediction interval ordering and normal-quantile parity;
- optional reuse of an existing filter result;
- datetime and range index handling;
- multivariate shape/covariance invariants;
- explicit invalid-configuration failures;
- immutable forecast arrays;
- full Stage 8–10 regression suite remains green.
