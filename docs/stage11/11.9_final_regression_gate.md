# Stage 11.9 — Final Stage 11 Regression Gate

## Purpose

Stage 11.9 is the final integration gate before the Stage 11 freeze. It verifies that the complete state-space extension remains compatible with the frozen Stage 8, Stage 9 and Stage 10 contracts while the Stage 11.1–11.8 additions compose deterministically.

## Required public workflow

The regression gate covers the public state-space path:

1. `estimate_local_level`
2. `kalman_filter`
3. `kalman_smoother`
4. `kalman_innovation_diagnostics`
5. `state_space_adequacy`
6. `kalman_forecast`
7. `run_local_level_workflow`

The gate also checks that the existing Stage 8 and Stage 9 public APIs remain importable and operational.

## Acceptance criteria

- Full test suite passes.
- Stage 8 correlogram schema remains unchanged.
- Stage 9 identification → estimation → validation → selection remains operational.
- Stage 10 Kalman filtering result shapes, missing-value counts and immutable arrays remain unchanged.
- Stage 11 smoothing, diagnostics, adequacy and forecasting remain deterministic.
- The integrated Stage 11 workflow reuses one canonical filter result downstream.
- Forecast intervals preserve `lower <= forecast <= upper` for every finite marginal forecast.
- No public API is removed or silently renamed.
- No frozen numerical convention is changed to make the regression pass.

## Freeze gate

After local validation, the repository must pass the existing GitHub Actions matrix for Python 3.10, 3.11, 3.12 and `examples-and-docs`. Only then may Stage 11.10 create the permanent Stage 11 freeze tag.
