# Stage 11.3 — State-Space Likelihood Estimation

Stage 11.3 adds deterministic Gaussian maximum-likelihood estimation for the scalar local-level model while preserving the Stage 10 filter and the Stage 11.1–11.2 contracts. Stage 11.2 is preserved as an auditable rollback point on `stage-11.2-freeze` at commit `5f9a9c4b3ee38060343e095a9640fedfd15061a6`.

## Public API

```python
from stochx.timeseries import LocalLevelEstimateResult, estimate_local_level

result = estimate_local_level(
    observations,
    initial_level=None,
    initial_variance=None,
    start=(0.1, 0.9),
)
```

The estimator fits only the non-negative process and observation variances. The local-level transition/design equations and Stage 10 missing-observation semantics remain unchanged.

## Numerical contract

Parameters are optimized in log-variance space with deterministic L-BFGS-B settings and a fixed caller-supplied starting point. The objective is the negative Gaussian log likelihood returned by the frozen Stage 10 filter.

The result records process variance, observation variance, log likelihood, AIC, BIC, convergence status, iteration count, message, and a fitted scalar `LinearStateSpace` model.

AIC uses `-2*loglik + 2*k` with `k=2`. BIC uses `-2*loglik + k*log(effective_nobs)`.

## Missing observations

NaN observations are passed through the frozen Stage 10 filter. Finite scalar observations contribute to likelihood; missing scalar observations do not.

## Determinism

The same data, initialization, and starting values must produce numerically identical parameter estimates and likelihood diagnostics within the repository floating-point tolerance policy. No randomness is used.

## Failure semantics

Reject fewer than two rows, all-missing samples, infinite observations, invalid initial conditions, and non-positive/non-finite starting variances with explicit `ValueError`s.

## Compatibility

Stage 11.3 must not modify `LinearStateSpace`, `KalmanFilterResult`, `kalman_filter`, `local_level_filter`, `KalmanSmootherResult`, `kalman_smoother`, `KalmanForecastResult`, or `kalman_forecast`. Stage 8 and Stage 9 contracts remain unchanged.

## Acceptance criteria

- deterministic repeated estimation;
- non-negative estimated variances;
- finite likelihood and information criteria;
- missing-observation handling through the frozen filter;
- auditable convergence metadata;
- fitted model reproduces estimated variance parameters;
- invalid configurations fail explicitly;
- public import/export succeeds;
- full Stage 8–11.2 regression suite remains green.
