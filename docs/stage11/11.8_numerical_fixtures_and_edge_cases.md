# Stage 11.8 — Numerical Fixtures and Edge-Case Hardening

Stage 11.8 freezes deterministic reference behavior for the complete Stage 11 local-level workflow and adds explicit edge-case regression coverage.

## Fixture policy

Fixtures cover estimation, filtering, smoothing, innovation diagnostics, adequacy reporting, and optional forecasting. Expected values are recorded from independent scalar recursions or frozen analytic calculations; tolerances are explicit and must not be widened to conceal numerical regressions.

## Required invariants

- Repeated execution with identical inputs is deterministic.
- Missing observations preserve Stage 10 scalar accounting and time dimensions.
- Fully missing rows remain prediction-only rows.
- Smoothing reuses the exact filtering result.
- The final smoothed state/covariance equals the final filtered state/covariance.
- Forecast outputs preserve horizon, shape, index, and interval ordering.
- Numerical result arrays remain read-only.
- Invalid input produces explicit failures rather than silent fallback behavior.

## Edge cases

The regression suite covers single-observation filtering/smoothing where supported, mixed missingness, all-missing observations, near-singular innovation covariance, minimal diagnostic samples, zero forecast steps, invalid horizons/alphas/lags, and repeated workflow execution.

## Acceptance gate

Stage 11.8 is complete only when the complete local test suite remains green and the Stage 8, Stage 9, and Stage 10 compatibility suites remain unchanged and green. The full CI matrix must pass before Stage 11.9 begins.
