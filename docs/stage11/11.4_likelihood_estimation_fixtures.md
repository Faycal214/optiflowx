# Stage 11.4 — Likelihood-Estimation Fixtures and Regression Hardening

Stage 11.4 freezes deterministic numerical references for the Stage 11.3 local-level Gaussian maximum-likelihood estimator.

## Scope

This stage does not add a new public API. It validates `estimate_local_level()` against deterministic fixtures and protects the Stage 11.3 contract.

## Public API under test

```python
from stochx.timeseries import LocalLevelEstimateResult, estimate_local_level
```

## Fixture requirements

Fixtures use explicit deterministic observations and configuration. Expected estimates are generated independently from the StochX optimizer path and recorded with documented tolerances.

Required cases:

- synthetic local-level series with non-zero process and observation variance;
- observation series containing NaNs;
- deterministic repeatability from identical inputs;
- explicit initial conditions;
- invalid starting variances and invalid observations.

## Frozen conventions

- optimization occurs in log-variance space;
- the Stage 10 Kalman filter supplies the Gaussian likelihood;
- the estimator uses fixed deterministic L-BFGS-B configuration;
- AIC uses two estimated variance parameters;
- BIC uses the effective observed scalar measurement count;
- estimated variances are non-negative;
- missing observations retain Stage 10 semantics.

## Compatibility

Stage 11.4 must not modify `LinearStateSpace`, `KalmanFilterResult`, `kalman_filter`, `local_level_filter`, `KalmanSmootherResult`, `kalman_smoother`, `KalmanForecastResult`, or `kalman_forecast`.

Stage 8 and Stage 9 contracts remain frozen.

## Acceptance criteria

- deterministic reference fixture passes within the declared tolerance;
- repeated estimation returns numerically identical results within tolerance;
- missing observations are accounted for through the Stage 10 filter;
- AIC/BIC recompute exactly from the reported likelihood and parameter count;
- invalid configurations fail explicitly;
- the full repository test suite remains green;
- the existing CI matrix remains green before the next Stage 11 step.
