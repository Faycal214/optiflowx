# Stage 11.1 — State-Space Extension Contract

## Purpose

Stage 11 extends the frozen Stage 10 linear-Gaussian state-space and Kalman-filter foundation with state estimation over the complete sample. Stage 11.1 freezes the public RTS smoothing contract.

## Frozen Stage 10 baseline

Stage 11 consumes, without redefining:

```python
LinearStateSpace
KalmanFilterResult
kalman_filter()
local_level_filter()
```

Filtering order, missing-observation accounting, covariance conventions, log likelihood, shapes, aliases, and immutability remain unchanged.

## Public API

```python
from stochx.timeseries import KalmanSmootherResult, kalman_smoother

result = kalman_smoother(observations, model, filter_result=None)
```

`KalmanSmootherResult` exposes:

- `smoothed_state`
- `smoothed_cov`
- `filter_result`
- `nobs`
- `states` alias for `smoothed_state`
- `covariances` alias for `smoothed_cov`

## Numerical invariants

For time points `t = N-2, ..., 0`, the RTS recursion is:

```text
J_t = P_t F' (P_{t+1|t})^{-1}
x_{t|T} = x_t + J_t (x_{t+1|T} - x_{t+1|t})
P_{t|T} = P_t + J_t (P_{t+1|T} - P_{t+1|t}) J_t'
```

The implementation must use stable linear solves rather than explicit inverses and symmetrize smoothed covariance matrices.

Required invariants:

- `smoothed_state.shape == (nobs, n_state)`;
- `smoothed_cov.shape == (nobs, n_state, n_state)`;
- final smoothed state/covariance equal the final filtered state/covariance;
- one-observation smoothing equals filtering;
- fully missing rows remain present and receive prediction-only filtering before smoothing;
- Stage 10 `effective_nobs` and `missing_observations` are unchanged;
- repeated execution is deterministic;
- returned numerical arrays are immutable.

## Missing observations

Stage 11 inherits Stage 10's scalar-observation semantics exactly. Partial rows update only observed dimensions. Fully missing rows perform no measurement update and contribute no likelihood term in the forward filter.

## Filter-result reuse

A compatible `filter_result` may be supplied to avoid a second forward pass. Dimension and missingness compatibility must be checked. Incompatible results must raise an explicit `ValueError` rather than being silently ignored.

## Failure semantics

Reject invalid dimensions, incompatible filtering results, empty observations, and non-finite non-NaN observations explicitly.

## Compatibility rules

Stage 11 must not alter Stage 8 correlogram numerical/table/plotting behavior or Stage 9 Box–Jenkins identification, estimation, validation, selection, and forecasting contracts.

Stage 10 APIs remain frozen and must continue to pass their complete regression suite.

## Acceptance tests

Stage 11.1 requires focused tests for:

- scalar deterministic RTS parity;
- multivariate shapes;
- final-time equality;
- one-observation behavior;
- partial and full missing rows;
- covariance symmetry;
- filter-result reuse;
- incompatible filter-result rejection;
- input immutability;
- deterministic repeated execution.

Full repository tests and the existing Python 3.10/3.11/3.12 plus examples-and-docs CI matrix must remain green before Stage 11.2 begins.
