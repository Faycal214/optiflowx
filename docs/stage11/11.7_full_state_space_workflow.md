# Stage 11.7 — Full State-Space Workflow Integration

Stage 11.7 provides one deterministic composition layer for the local-level state-space workflow:

```text
observations
    ↓
local-level likelihood estimation
    ↓
Kalman filtering
    ↓
RTS smoothing
    ↓
innovation diagnostics
    ↓
state-space adequacy tests
    ↓
optional multi-step forecasting
```

## Public API

```python
from stochx.timeseries import StateSpaceWorkflowResult, run_local_level_workflow
```

`run_local_level_workflow()` is an orchestration API. It does not replace or alter the underlying Stage 10/11 numerical APIs. The returned `StateSpaceWorkflowResult` exposes the individual stage results for auditability.

### Result fields

- `estimation`: `LocalLevelEstimateResult`
- `filter_result`: `KalmanFilterResult`
- `smoother`: `KalmanSmootherResult`
- `innovation_diagnostics`: `KalmanInnovationDiagnosticsResult`
- `adequacy`: `StateSpaceAdequacyResult`
- `forecast`: `KalmanForecastResult | None`

Convenience properties:

- `success` mirrors estimation success.
- `adequate` mirrors the configured innovation-adequacy decision.

## Contract

The workflow uses the estimated local-level model for the single canonical forward filtering pass. That exact `KalmanFilterResult` is reused by the smoother, diagnostics, and optional forecast.

Missing observations retain Stage 10 semantics. They remain in the time axis, contribute no scalar likelihood term, and propagate through smoothing and downstream diagnostics without fabrication.

The orchestration layer is deterministic for identical inputs and configuration. It does not mutate observations or the underlying model/results.

## Compatibility

Stage 8 and Stage 9 APIs are untouched. Stage 10 filtering remains the numerical foundation. Stage 11.1–11.6 public result types remain independently usable and their numerical semantics are unchanged.

## Acceptance criteria

- Full workflow returns all required intermediate results.
- Filter result is reused by smoothing and forecasting.
- Forecast is optional when `forecast_steps=0`.
- Missing-observation counts remain consistent across filtering and innovation diagnostics.
- Repeated execution is numerically deterministic.
- Invalid workflow arguments fail explicitly.
- Full Stage 8/9/10/11 regression suite remains green.
