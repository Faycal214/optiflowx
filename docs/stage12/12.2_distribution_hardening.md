# Stage 12.2 — Distribution Hardening

## Purpose

Stage 12.2 hardens the StochX distribution surface before the release candidate. The goal is to verify that the source tree, source distribution, and wheel all describe and install the same package, version, and public runtime surface.

## Scope

This stage covers:

- source distribution generation;
- wheel generation;
- Twine metadata validation;
- clean-environment installation from the built wheel;
- import and version verification after installation;
- preservation of the existing `pyproject.toml` package metadata;
- CI coverage for the distribution path.

This stage does **not** change the frozen Stage 8–11 numerical or API contracts and does not bump the public version yet.

## Required artifact properties

A successful build must produce both:

- one `.tar.gz` source distribution;
- one `.whl` wheel.

The artifacts must pass:

```text
python -m twine check dist/*
```

The installed wheel must expose:

```python
import stochx
stochx.__version__
```

and the installed version must agree with the distribution metadata.

## Compatibility requirements

The distribution must preserve the canonical public namespaces:

```python
import stochx
import stochx.stochastic
import stochx.timeseries
```

The release package must continue to include the `stochx` package tree and must not resurrect the legacy project identity.

The existing single-source version policy remains authoritative: the package version is defined in `stochx/__init__.py` and consumed by the build configuration.

## CI requirement

The GitHub Actions workflow must include a dedicated distribution-hardening job that:

1. installs build tooling;
2. builds sdist and wheel;
3. runs `twine check`;
4. creates a clean virtual environment;
5. installs the generated wheel without relying on the source checkout;
6. imports the installed package;
7. verifies the installed version and public namespaces.

## Acceptance criteria

- [ ] `python -m build` produces sdist and wheel.
- [ ] `twine check dist/*` passes.
- [ ] The wheel installs successfully into a clean virtual environment.
- [ ] `import stochx` succeeds from outside the source tree.
- [ ] Installed version equals the project version.
- [ ] `stochx.stochastic` imports successfully.
- [ ] `stochx.timeseries` imports successfully.
- [ ] No legacy project identity is present in the built package metadata.
- [ ] Existing full tests remain green.
- [ ] Existing examples-and-docs checks remain green.
- [ ] Python 3.10, 3.11, and 3.12 CI jobs remain green.
- [ ] No Stage 8–11 numerical or public API behavior changes.
