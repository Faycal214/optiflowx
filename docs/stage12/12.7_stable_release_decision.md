# Stage 12.7 — Stable Release Decision

## Decision

StochX promotes the validated `0.3.0rc1` contract to stable version `0.3.0`.

The release candidate passed the complete local and CI validation gate before promotion. The stable release does not introduce new numerical methods, public APIs, or behavioral changes beyond the frozen Stage 8–11 surface.

## Scope of the promotion

- package version: `0.3.0`
- citation version: `0.3.0`
- changelog release: `0.3.0`
- frozen Stage 8–11 public and numerical contracts remain unchanged
- existing `stochx`, `stochx.stochastic`, and `stochx.timeseries` import boundaries remain canonical

## Required release validation

- full test suite
- Python 3.10, 3.11, and 3.12
- examples-and-docs
- source and wheel distribution builds
- Twine metadata validation
- clean wheel installation
- installed-package version verification
- strict documentation build

## Release-tag policy

The final `v0.3.0` tag must identify the exact validated `main` commit after this promotion. No source, documentation, workflow, or release metadata changes are permitted between final validation and tagging.

- [ ] source version is `0.3.0`

- [ ] Stage 8–11 contracts remain unchanged

- [ ] Python 3.12 passes

- [ ] distributions build and validate
